# Mords Wer Pinute

A terminal-based typing practice application written in C.

## About

Mords Wer Pinute is a small TUI typing trainer built with C and ncurses.

The goal of the project is to practice typing.

## Current Status

Work in progress.

The project has a basic interface.

## Technologies

- C17
- ncurses
- Doxygen
